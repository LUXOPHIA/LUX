# LUX.Complex.CP1

[English](../README.md) | [日本語](README.md)

`LUX.Complex.CP1` は斉次複素座標 `[Z:W]` を保持する `TSingleCP1` / `TDoubleCP1` を提供する。値は `Z / W` であり、非零の `Z` と `W = 0` の組が無限遠点を表す。ユニット検索パスに LUX のルート、`Complex`、`Complex/CP1` ディレクトリを追加し、`LUX.Complex.CP1` を uses に指定する。例えば CP1 型の変数で `Z := Pow2( Z ) + C` と書けば二次反復になる。依存先は `LUX.Complex` と RTL であり、描画処理には依存しない。

正規化では4成分を2の冪で一様に拡大・縮小する。浮動小数点のレコードなので丸めやアンダーフローは残り、不定形に与える値は実装上の規約である。`Re` / `Im` は通常の成分値を取り出す。用途固有の観測式・着色式はアプリケーション側で定義する。現状の `Abs2` には保守的なオーバーフロー判定があり、`Abso` は `Sqrt(Abs2)` を計算するため、絶対値自体を表現できる場合でも無限大になることがある。
