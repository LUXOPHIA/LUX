# LUX.Complex.CP1

[English](../README.md) | [日本語](README.md)

`TSingleCP1` / `TDoubleCP1` は複素数を斉次座標 `[Z:W]` で保持し、値は `Z / W` である。非零の分子と `W = 0` の組が、単一の無限遠点を表す。ユニット検索パスに LUX のルート、`Complex`、`Complex/CP1` を追加する。

両レコードは、対応する通常の複素数レコード `TSingleC` / `TDoubleC` の公開機能を備える。

| 機能 | CP1 の API |
|---|---|
| 成分 | 読み書きできる `R` / `I`。`Re` / `Im` は同じ成分の別名 |
| 虚数単位 | `Imaginary` |
| 絶対値 | `Abs2`、読み書きできる `Abso` |
| 方向 | 読み書きできる `Unitor`、ラジアン単位の読み取り専用 `Angle` |
| 共役 | 読み書きできる `Conj` |
| 算術 | 単項符号、加減乗除、実数との積・除算 |
| 乱数 | 既定値・実数・通常複素数・CP1 を偏差指定に取る `RandG`、`RandBS1`、`RandBS2`、`RandBS4` |
| 変換 | 通常複素数からの暗黙変換、通常複素数への明示変換、精度間の変換 |
| 関数型 | `TSingleCP1Func`、`TDoubleCP1Func` |
| 初等関数 | `Pow`、`Roo2`、`Exp`、`Expi`、`Ln`、`Sin`、`Cos`、`Tan`、`ArcSin`、`ArcCos` |

CP1 固有の `Zero`、`Infinity`、`IsZero`、`IsInf`、等値演算子、`Pow2` も備える。`Z := Pow2(Z) + C` で二次反復を書ける。描画処理には依存しない。

有限非零の値では、setter の意味を通常型と揃えている。`Abso := A` は `A * Unitor`、`Unitor := U` は `|Self| * U` を代入し、引数 `U` を再正規化しない。`Conj := C` は `C` の共役を代入する。成分への代入はもう一方の成分を保持する。ただし通常型のフィールドと異なり `R` / `I` はプロパティなので、`var` 引数としては渡せない。内部の正規化は4成分を2の冪で一様に拡大・縮小するが、丸めやアンダーフローによる情報損失は残る。

`Abso` は分子・分母の `Hypot` の比で求める。`Abs2` は仮数と指数を分離してから二乗し、返却型の上限でオーバーフローを判定する。方向は分子・分母それぞれの方向を正規化して求める。`Ln` は絶対値の対数の差、`Roo2` は偏角の半分と分子・分母の絶対値の平方根を使う。`ArcCos` は通常型と同じ対数式を使う。分岐切断上の結果には符号付きゼロと浮動小数点の丸めの影響が残る。

無限遠点・不定形に対する値は実装上の規約であり、数学的に一意な値ではない。既存の `0/0`、無限遠点同士の除算の規約は `Infinity` なので、ゼロと無限遠点の `Unitor` も `Infinity` を返す。`Angle` はゼロで0、無限遠点で NaN。無限遠点への成分代入は値を変更せず、共役も無限遠点のままとする。無限遠点の通常成分の読み取りは正の無限大を返す。初等関数の無限遠点での値にも個別の実装規約がある。斉次座標 `[0:0]` は有効な CP1 の点ではない。

乱数生成は通常型の生成器に委譲し、分布、引数の解釈、乱数の消費順序を共通にする。複素平面上の標本であり、球面上の一様分布ではない。観測式・着色式はアプリケーション側で定義する。
